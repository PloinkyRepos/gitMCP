gitAssistant Agent Documentation

This repository currently hosts one Ploinky agent: gitAgent.

The agent is integrated in Ploinky and consumed by Explorer workflows from the internal AssistOSExplorer repository.

At runtime, Git functionality is exposed through MCP tools and executed by gitAgent/tools/git_tool.sh.

What this agent does

  • Acts as an intermediary between Explorer UI actions and Git command execution.
  • Exposes a controlled MCP tool surface defined in gitAgent/mcp-config.json.
  • Validates repository paths against workspace roots before running Git operations.
  • Provides optional GitHub auth flows for push and pull through MCP-accessible auth tools.
